## 当时学到的事情

形式化工具可以检查规则的结构、引用与逻辑蕴含，但无法自动保证 LLM 提供的前提符合现实，也无法保证没有遗漏危险机制。异步补充减少同步阻塞，却不能让缺少关键事实的新任务立即被证明安全。旧方案主要检查当前事实与动作契约，尚未预测候选动作执行后的系统和环境演化。

湿润状态的续期等工程功能不等于已经解决湿润识别。FineART 原生接口适配也不等于公开权重已具备可靠 VQA 能力。大多数文本补充耗时约一分钟，个别思考模式调用达到 467.2 秒。

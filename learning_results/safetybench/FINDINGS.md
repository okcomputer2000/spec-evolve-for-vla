# 十题测试驱动优化：结论

固定随机十题已经逐题运行，共 26 个独立动作判断。开发过程中发现问题后修改通用代码或提示，并仅复核相应失败项。首次记录有 4 题完整重建标准答案，最新记录有 7 题重建正确、3 题无法唯一重建。所有首次记录与后续运行均保留。

**这些是跨版本、跨配置的开发记录，不是统一最终版本的独立测试准确率。** 第七题的最新结果含一次开启本地模型思考的复核，其余主要使用关闭思考的配置。标准答案和其他候选动作不进入模型；未知或多个动作均 unsafe 时，重建器弃答，不猜选项。

## 测试实际推动了哪些修改

- 修复反馈中的危险/安全公式重复取反，避免修复轮改变极性。
- 使用本地官方 tokenizer 计数，不再把 UTF-8 字节数误当 token 数而提前拒绝完整修复包；真正超预算仍拒绝，不截断历史。
- 标识符和部分修复约束进入 JSON schema；由编译器原样填入任务、动作及对象绑定，避免模型抄错原文。
- 谓词显式区分实际状态、提案属性和稳定常识能力；事件/时间效果只能修改实际状态，计时器也必须锚定实际状态。
- 增加文本/视觉来源 ID、原时间检查、不确定视觉观察的限制、空来源不能证明 false；调用失败和调用时输入快照也保留。
- 修复脚本未传入场景的问题；评估问题与任务目标分开，完整问题仍保留为上下文。
- 针对保护动作误报、否定漏读和未说明接触方式优化通用提示；部分问题改善，部分问题未改善。

## 耗时与验证范围

大多数最新动作的后台补充耗时约一分钟。第七题的否定动作使用思考模式后改为正确，但耗时 467.2 秒，因此没有将其设为默认配置。近期动作还记录了首次异步返回和补充后的复核延迟，它们与后台补充时间分开。

最终代码的 50 项单元检查通过，日志见 unit_tests_final_20261107.txt。此次没有进行大规模评测、消融、闭环 VLA 或真实机器人实验。旧实验统一归档未改动。

形式化验证能拒绝结构不合法、来源不合法或逻辑不成立的候选，但**不能证明模型没有编造危险机制或遗漏常识**。这轮最重要的发现是：工程链路已经更可追踪，剩余瓶颈主要在补充前提的语义正确性。

本地 qwen3-vl:4b 已安装。一次存档原图的完整结构化报告复核成功，包含 8 个对象、8 条观察、对象细节与不确定性，报告通过字段、ID 和引用校验。图片只进入视觉模型，文本推理模型接收报告及原始结构化上下文；报告及推导事实可以通过来源 ID 建立联系。
